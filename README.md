# AI Query System

## Overview

AI Query System is a lightweight Spring Boot web application that allows users to submit questions through a web interface and receive AI-generated responses using the OpenRouter API.

This project is being developed as part of a DevOps Internship Assignment.

## Tech Stack

- Java 25
- Spring Boot
- Maven
- HTML
- CSS
- JavaScript
- OpenRouter API

## Current Features

- AI Query API
- Web Interface
- REST Backend
- OpenRouter Integration
