# 01 - Application Setup

## Objective

Build a lightweight AI Query System that will serve as the application for our DevOps project.

---

## Features Implemented

- Spring Boot backend
- REST API
- OpenRouter Integration
- HTML/CSS/JavaScript frontend
- AI response generation

---

## Technologies Used

| Technology | Purpose |
|------------|---------|
| Java 25 | Backend |
| Spring Boot | REST API |
| Maven | Build Tool |
| HTML | Frontend |
| CSS | Styling |
| JavaScript | API Calls |
| OpenRouter | AI Model |
