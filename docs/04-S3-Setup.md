# 04 - Amazon S3 Setup

## Objective

Create an Amazon S3 bucket to store deployment artifacts, backups, and reports.

## Bucket Configuration

Bucket Name:
- devops-ai-query-<your-name>-2026

Security:
- Block Public Access Enabled
- Server-side Encryption Enabled (SSE-S3)
- Versioning Enabled

## Folder Structure

backups/

artifacts/

reports/

## Purpose

backups/
Stores application and deployment backups.

artifacts/
Stores application build artifacts generated by the CI/CD pipeline.

reports/
Stores performance testing reports and generated outputs.

## Future Integration

GitHub Actions will automatically upload build artifacts to the artifacts/ folder during deployment.
